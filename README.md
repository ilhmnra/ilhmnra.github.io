# Aulia Ilham Portfolio

Static personal portfolio for Aulia Ilham Nur Alfian. Built with semantic HTML, CSS and a small progressive enhancement script. No build step, tracking scripts, account system or backend.

## Preview

Run `python -m http.server 8765` in this directory, then open http://localhost:8765.

## GitHub Pages

Publish the `main` branch from `/ (root)` in Settings → Pages. All local assets and navigation links use relative paths, so this works at a repository URL or a user site URL.

## Edit

Page content is in the HTML files. Shared styling and filtering are in `assets/styles.css` and `assets/site.js`. The public resume is `assets/Aulia-Ilham-Resume.pdf`. Illustrations are original conceptual diagrams, not screenshots of internal company systems.
